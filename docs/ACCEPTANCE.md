# Проверка перед практическим использованием

Статус всех сценариев ниже: **не выполнено на Android**. Отдельные JVM-тесты ядра не заменяют эти проверки.

| Сценарий | Ожидаемый результат |
|---|---|
| CI | Unit tests, lintDebug, assembleDebug и apksigner завершаются успешно; INTERNET отсутствует в итоговом APK |
| Установка Android 12/15/16 | APK устанавливается; нет мгновенного падения; отдельно проверить Samsung S21 Ultra |
| Базовый режим без Usage Access | Видны система, батарея, список и разрешения; недоступные данные отмечены, запрос обязательного расширенного доступа не появляется |
| Выдан Usage Access | После повторного сканирования доступны возвращенные Android агрегаты; отказ отдельного API не останавливает весь отчет |
| Отказ и отзыв Usage Access во время проверки | Нет падения; частичные данные/ошибки отмечены в покрытии |
| Системное приложение со старым targetSdk | Не помечается подозрительным только за возраст targetSdk |
| Законный мессенджер с широкими разрешениями | Приоритет объясняется; нет утверждения «вирус» и автодеактивации |
| Приложение лишь объявляет overlay/install APK | Декларация не отображается как доказанный выданный доступ |
| Разрешение BOOT_COMPLETED | Нет утверждения о фактическом запуске или текущей работе |
| Работа в профилях | Явно обозначен текущий профиль; Secure Folder/другие профили не выдаются за полностью проверенные |
| RAM | Общий снимок присутствует; чужая память не подменяется нулем/размером APK |
| Накопитель | Сумма = appBytes + dataBytes, cacheBytes не прибавляется повторно |
| Общий UID | Трафик помечен общим; нет ошибочной суммы по нескольким пакетам |
| Частичная сеть | Неудачный мобильный запрос не обнуляет доступный Wi-Fi; статусы сохранены |
| Батарея с неподдерживаемыми свойствами | null/«не поддерживается», без отрицательных sentinel-значений и ложного износа |
| Наблюдение | Точка раз в 30 с, лимит 120, прекращение после сворачивания/блокировки/поворота |
| Отмена сканирования | Остановка между запросами; прежний результат остается; частичный отчет не объявлен полным |
| Поворот во время сканирования | Новый Activity получает состояние контроллера; старый не удерживается наблюдателем |
| Гибель процесса | Сохраненные отчеты доступны в истории; не обещано восстановление несохраненной проверки |
| Экспорт без приложений | Нет пакетов/имен/источников ни в apps, ни в findings, ни в ошибках |
| Экспорт без usage | Нет временных агрегатов, lastUsed и выводов на их основе |
| Экспорт без network | Нет сетевых счетчиков, ни на уровне приложения, ни устройства |
| Необычные названия | Кавычки, переводы строк, emoji и текст-инструкции остаются данными, JSON валиден |
| Sharesheet | Выбранный получатель читает только предоставленный отчет; provider не экспортирован |
| Подмена URI/попытка записи | Произвольные пути, `..`, неподходящие имена и режимы rw/w отклоняются |
| Сохранение/отмена выбора файла | Успешное сохранение JSON/TXT; отмена без ошибки, повторная попытка работает |
| История | Сохраняются до 10 отчетов, порядок по времени, экспорт старого не подменяется текущим |
| Очистка истории | Удаляются локальные отчеты, текущие результаты и staged-файлы, внешние копии не обещаются удаленными |
| Доступность UI | Проверить TalkBack, крупный шрифт, небольшой экран, жестовую навигацию и экранную клавиатуру |
| Отсутствие скрытой активности | Нет INTERNET, SDK аналитики, служб, boot receivers, запроса Accessibility или Device Admin у аудитора |
