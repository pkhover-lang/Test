AI / PHONE AUDITOR · ИСХОДНЫЙ ПРОЕКТ 1.0

Получить APK,
пользуясь телефоном

Диагностика — на Android. Сборка — в GitHub Actions. Компьютер, root и ADB пользователю не нужны.

Готовый APK пока не собран.

Здесь инструкция для сборки исходников. В среде подготовки не было Android SDK и не удалось загрузить инструменты. Проверены 30 сценариев ядра и JSON; Android-сборка и запуск на устройстве еще не проверялись.

01 · Сохрани исходники

Скачай из сообщения файл AI-Phone-Auditor-source.zip. Не переименовывай и не распаковывай: сервер сам извлечет файлы. В этом ZIP нет установочного APK.

02 · Создай репозиторий

В браузере открой GitHub, войди в аккаунт и создай репозиторий ai-phone-auditor. Выбери Private и добавление README. При необходимости включи в браузере «Версия для ПК» — это лишь режим отображения.

Нужны аккаунт и доступные Actions. Сборка использует серверные ресурсы и квоту аккаунта. Диагностические отчеты телефона в GitHub загружать не нужно.

03 · Загрузи ZIP

Add file → Upload files → Choose your files. Загрузи AI-Phone-Auditor-source.zip прямо в корень репозитория. Нажми Commit changes.

04 · Добавь сценарий сборки

Открой Add file → Create new file. Имя файла:

.github/workflows/build-apk.yml

Скопируй весь текст ниже в редактор и сохрани через Commit changes. YAML в корне репозитория не запустится — нужен именно указанный путь.

При недоступном копировании выдели текст в поле вручную.

05 · Дождись результата

Actions → Build APK → Run workflow (или открой автоматически запущенную сборку). Workflow выполнит тесты, Lint, сборку APK и проверку подписи.

При зеленом статусе скачай внизу страницы Artifacts → AI-Phone-Auditor-APK и распакуй архив. Внутри должен быть AI-Phone-Auditor-1.0.0-debug.apk с контрольной суммой и отчетом подписи.

При красном статусе открой упавший шаг и сохрани текст ошибки. Зеленый CI подтверждает сборку, но не тестирование на твоем Samsung. Артефакт хранится 7 дней.

06 · Установи и проверь

Открой полученный APK. Для установки вне магазина Android может запросить разрешение у браузера или файлового менеджера. Не отключай Play Protect и не обходи предупреждение о конкретной угрозе: сначала проверь причину.

В приложении начни с Обзор → Начать диагностику. Для дополнительных данных включи Usage Access в разделе Действия, вернись и повтори проверку.

Самому аудитору не нужны специальные возможности, администратор, VPN, SMS, контакты, фото или геолокация.

Передать результат на анализ

Отчет → выбрать состав данных → Предпросмотр → Поделиться JSON или сохранить JSON/TXT и вручную прикрепить в нужный чат. Список программ может раскрывать личные сведения. Время использования и сеть по умолчанию исключены.

Точные проценты батареи по чужим приложениям, полный автозапуск и антивирусный вердикт здесь не выдаются. Подозрительные сочетания разрешений означают необходимость проверки, а не доказанное заражение.
